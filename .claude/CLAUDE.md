# Testing

This is important. Use Playwright MCP to test your changes, make sure nothing broke and the data is being displayed exactly as before. In dev mode, the data being displayed in the UI should be in the json files in the data directory. Check the data being displayed against the source data files. 
Try checking the running app before changes, to confirm you know what you're updating.
Check if the dev server is already running and ask about it if you cannot access it.
